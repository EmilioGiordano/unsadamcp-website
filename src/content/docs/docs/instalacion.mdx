No hace falta clonar nada: `npx` descarga el paquete [`unsada-mcp`](https://www.npmjs.com/package/unsada-mcp) y lo ejecuta. Necesitas dos cosas instaladas.

| Requisito | Cómo comprobarlo |
|---|---|
| Node.js 22 o más nuevo | `node -v` muestra `v22` o mayor |
| Microsoft Edge o Google Chrome | Edge ya viene con Windows |

## 1. Instalación de Node

<Tabs syncKey="os">
  <TabItem label="Windows">
    <Steps>

    1. Descarga el instalador **LTS** de [nodejs.org](https://nodejs.org/) y ejecútalo con las opciones por defecto.

    2. Abre una terminal nueva (PowerShell o Windows Terminal) y comprueba la versión:

       ```powershell
       node -v
       ```

    </Steps>

    <Aside>Si ya tenías una terminal abierta antes de instalar, ciérrala y abre otra: si no, no encuentra `node`.</Aside>
  </TabItem>
  <TabItem label="macOS">
    Con el instalador de [nodejs.org](https://nodejs.org/) o con Homebrew:

    ```bash
    brew install node
    node -v
    ```
  </TabItem>
  <TabItem label="Linux">
    Usa el gestor de tu distribución o [nvm](https://github.com/nvm-sh/nvm), que instala versiones nuevas sin tocar las del sistema:

    ```bash
    nvm install --lts
    node -v
    ```

    También necesitas Google Chrome o Microsoft Edge instalado. Si quieres elegir cuál usa, indícalo con `UNSADA_BROWSER` (ver [Comandos y variables](../comandos/)).
  </TabItem>
</Tabs>

## 2. Inicio de sesión

```bash
npx -y unsada-mcp@latest login
```

Se abre una ventana del aula directo en la pantalla de Google. Entras con tu cuenta y la ventana se cierra sola. Está explicado paso a paso en [Primer inicio de sesión](../primer-login/).

## 3. Conexión con tu cliente

<Tabs syncKey="client">
  <TabItem label="Claude Code">
    En una terminal. Con `-s user` queda disponible en todas tus carpetas.

    ```bash
    claude mcp add unsada -s user -- npx -y unsada-mcp@latest
    ```

    Comprueba que aparece con `claude mcp list`.
  </TabItem>
  <TabItem label="Claude Desktop">
    Abre **Settings → Developer → Edit Config** y agrega el servidor en `claude_desktop_config.json`:

    ```json
    {
      "mcpServers": {
        "unsada": { "command": "npx", "args": ["-y", "unsada-mcp@latest"] }
      }
    }
    ```

    En Windows el archivo está en `%APPDATA%\Claude\claude_desktop_config.json`. Cierra Claude Desktop por completo (también desde la bandeja del sistema) y ábrelo de nuevo.
  </TabItem>
  <TabItem label="Codex">
    En `~/.codex/config.toml` (en Windows, `%USERPROFILE%\.codex\config.toml`):

    ```toml
    [mcp_servers.unsada]
    command = "npx"
    args = ["-y", "unsada-mcp@latest"]
    ```
  </TabItem>
  <TabItem label="OpenCode">
    En `opencode.json`:

    ```json
    {
      "mcp": {
        "unsada": { "type": "local", "command": ["npx", "-y", "unsada-mcp@latest"] }
      }
    }
    ```
  </TabItem>
  <TabItem label="Cursor">
    En `~/.cursor/mcp.json` para todos tus proyectos, o en `.cursor/mcp.json` dentro de uno:

    ```json
    {
      "mcpServers": {
        "unsada": { "command": "npx", "args": ["-y", "unsada-mcp@latest"] }
      }
    }
    ```
  </TabItem>
</Tabs>

Reinicia el cliente y pregúntale algo, por ejemplo *"¿qué materias tengo este año?"*.

<Aside type="caution" title="En Windows, si el cliente no encuentra npx">
  Algunos clientes no lanzan `npx` directamente en Windows y el servidor no arranca (errores como `spawn npx ENOENT` o `-32000`). En ese caso usa `cmd /c` delante: por ejemplo `claude mcp add unsada -s user -- cmd /c npx -y unsada-mcp@latest`, o en JSON `"command": "cmd", "args": ["/c", "npx", "-y", "unsada-mcp@latest"]`. Más en [Solución de problemas](../problemas/).
</Aside>

## Actualizar

Para actualizar, reinicia tu agente: `@latest` baja la versión nueva al arrancar. Tras un release puede tardar unos minutos en aparecer.

## Desde el código

Si prefieres no depender de npm, o quieres modificarlo:

```bash
git clone https://github.com/EmilioGiordano/unsada-mcp
cd unsada-mcp
npm install
npm run build
claude mcp add unsada -s user -- node C:/ruta/a/unsada-mcp/build/index.js
```

Para iniciar sesión con esta instalación: `node build/index.js login`.
