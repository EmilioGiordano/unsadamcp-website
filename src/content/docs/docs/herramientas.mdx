El agente las elige solo según lo que le pidas. Todas devuelven JSON compacto, nunca HTML. Los ejemplos de esta página usan datos inventados.

| Herramienta | Qué hace | Escribe |
|---|---|---|
| [`unsada_list_courses`](#unsada_list_courses) | Tus cursos, los más recientes primero | No |
| [`unsada_get_course`](#unsada_get_course) | Secciones, actividades y recursos de un curso | No |
| [`unsada_open`](#unsada_open) | Foros, discusiones, páginas, carpetas, tareas y enlaces | No |
| [`unsada_read_file`](#unsada_read_file) | PDF, Word, PowerPoint, Excel, imágenes y texto, por partes | No |
| [`unsada_download`](#unsada_download) | Guarda archivos del aula en tu disco | En tu disco |
| [`unsada_list_assignments`](#unsada_list_assignments) | Tareas de un curso con vencimiento, estado y nota | No |
| [`unsada_get_grades`](#unsada_get_grades) | Notas de todos los cursos o el detalle de uno | No |
| [`unsada_get_calendar`](#unsada_get_calendar) | Vencimientos y eventos con hora exacta | No |
| [`unsada_login`](#unsada_login) | Abre el navegador para volver a entrar | Abre tu navegador |

Ninguna escribe en el aula.

## unsada_list_courses

Tus cursos, del año lectivo más nuevo al más viejo. Es el punto de partida: el `id` de cada curso lo usan las demás. Junta el tablero con el resumen de notas, porque el tablero deja afuera los cursos viejos.

```json
[{"id":2481,"name":"Bases de Datos","category":"Licenciatura en Sistemas","year":2026}]
```

## unsada_get_course

El contenido de un curso: sus secciones (semanas, unidades o pestañas) con actividades y recursos. Recorre todas las pestañas de los cursos con formato de pestañas. Las etiquetas traen su texto, que suele tener horarios de cursada y links de las clases. Las secciones vacías se omiten.

| Recibe | |
|---|---|
| `courseId` | El `id` que devolvió `unsada_list_courses` |

## unsada_open

Abre una dirección del aula y devuelve su contenido según el tipo (`kind`):

- `forum`: el foro con sus discusiones. Con `page` pide la página siguiente cuando `hasMorePages` es verdadero.
- `discussion`: la discusión con todos sus mensajes.
- `page`: una página con su texto.
- `folder`: una carpeta con sus archivos.
- `assignment`: una tarea con la consigna, los archivos, el estado de tu entrega y la devolución.
- `link`: un enlace externo, con la dirección a la que lleva.
- `file`: un archivo, para leer con `unsada_read_file`.

Las direcciones salen de los campos `url` que devuelven las otras herramientas.

## unsada_read_file

Lee un archivo del aula: PDF, Word (`.docx`), PowerPoint (`.pptx`), Excel (`.xlsx`), imágenes y texto. Las páginas escaneadas de un PDF llegan como imagen para que el modelo las lea.

El archivo llega por partes (páginas, diapositivas o bloques), las que entran en una respuesta. Si quedan más, `next` dice desde dónde seguir.

| Recibe | |
|---|---|
| `url` | Un archivo (`pluginfile.php`) o un recurso (`mod/resource/view.php`) |
| `from` | Opcional: página, diapositiva o bloque desde donde empezar |

```json
{"file":"Semana 3 - Transacciones.pdf","format":"pdf","unit":"page","total":14,"from":1,"to":8,"next":9}
```

<Aside>Los formatos que no puede leer (`.doc` y `.ppt` viejos, `.zip`, `.rar`, videos) devuelven un error con la dirección, para que lo descargues.</Aside>

## unsada_download

Guarda archivos del aula en tu disco: archivos sueltos, recursos y carpetas enteras (una carpeta del aula se guarda en una subcarpeta con su nombre). Es lo único que escribe, y solo dentro de la carpeta donde abriste el agente. Las reglas completas están en [Descargas](../descargas/).

| Recibe | |
|---|---|
| `urls` | Entre 1 y 50 direcciones, como las devuelven las otras herramientas |
| `directory` | Destino relativo a la carpeta donde abriste el agente, por ejemplo `Bases de Datos/Unidad 1` |

```json
{"directory":"C:\\Facultad\\Bases de Datos","saved":11,"skipped":1,"failed":0,"files":[{"url":"…","status":"saved","path":"Semana 3 - Transacciones.pdf","bytes":1843221}]}
```

## unsada_list_assignments

Las tareas de un curso: sección, nombre, vencimiento, estado de tu entrega y nota. Para la consigna completa y la devolución, el agente abre la tarea con `unsada_open`.

```json
[{"section":"Unidad 2","name":"TP2: Normalización","dueDate":"martes, 20 de octubre de 2026, 23:59","submission":"No entregado","grade":"-","url":"…"}]
```

## unsada_get_grades

Sin `courseId`, la nota total de cada curso. Con `courseId`, cada ítem calificado con nota, rango, porcentaje, ponderación y comentario.

```json
{"courseId":2481,"items":[{"item":"TP1: Modelo entidad-relación","grade":"8,00","range":"0–10","percentage":"80,00 %","feedback":"Revisá la cardinalidad de Inscripción."}]}
```

## unsada_get_calendar

Vencimientos de tareas, cierres de cuestionarios, exámenes y eventos de los cursos, en orden y en hora de Argentina, con el curso y la dirección de la actividad cuando la hay.

La exportación del calendario del aula pierde las horas, por eso el servidor lee las vistas de mes y de día. Si el rango tiene demasiados días con eventos, la respuesta trae `truncated` y conviene pedir uno más corto.

| Recibe | |
|---|---|
| `daysAhead` | Opcional: cuántos días hacia adelante, de 1 a 365. Por defecto 30 |
| `daysBack` | Opcional: cuántos días hacia atrás, de 0 a 30. Por defecto 0 |

## unsada_login

Abre una ventana del navegador para entrar al aula con Google. Casi nunca hace falta: cuando la sesión vence, el servidor la abre solo. Sirve para cambiar de cuenta o cuando la ventana no se ve.

```json
{"signedIn":true}
```
