El aula (Moodle 3.2) solo admite inicio de sesión con Google y no ofrece servicio para apps móviles. El servidor obtiene la sesión desde una ventana del navegador.

<Steps>

1. Ejecuta:

   ```bash
   npx -y unsada-mcp@latest login
   ```

2. Se abre una ventana de incógnito en la pantalla de Google. En Windows se usa Edge y, si no está, Chrome; en macOS y Linux, al revés.

3. Ingresa el correo, la contraseña y la verificación en dos pasos. La ventana se cierra al entrar al aula y la terminal muestra:

   ```
   Listo: sesión iniciada. Ya podés usar unsada-mcp desde tu cliente MCP.
   ```

</Steps>

Tienes cinco minutos para completar el inicio de sesión. Si la ventana se cierra antes, ejecuta el comando otra vez.

## Duración de la sesión

- Mientras el servidor está activo, renueva la sesión cada 10 minutos.
- Si la sesión vence, el servidor abre la ventana de inicio de sesión cuando el agente la necesita. La ventana no guarda datos, así que Google pide el correo, la contraseña y la verificación otra vez. El agente te pide que termines de iniciar sesión y después repite el pedido.
- Para cambiar de cuenta, pide al agente que vuelva a iniciar sesión (`unsada_login`) o ejecuta `logout` y después `login`.

## Estado de la sesión

```bash
npx -y unsada-mcp@latest status
```

Muestra `Conectado (sesión iniciada el …).` o `Sin sesión: corré unsada-mcp login.`

## Ubicación

| Sistema | Carpeta |
|---|---|
| Windows | `%APPDATA%\unsada-mcp` |
| Linux y macOS | `~/.config/unsada-mcp` |

La carpeta contiene solo la sesión del aula (`session.json`). La sesión de Google no se guarda. Para usar otra carpeta, define `UNSADA_MCP_HOME`.

Las versiones hasta la 0.3.0 guardaban un perfil del navegador con la sesión de Google. El servidor lo borra al iniciar o al ejecutar `login` o `logout`.

<Aside type="caution" title="Acceso a la sesión">
  Cualquier programa con acceso a esa carpeta puede usar la sesión del aula. En una computadora compartida, ejecuta `npx -y unsada-mcp@latest logout` al terminar.

  Un agente que ejecuta comandos de terminal puede leer `session.json`. Configúralo para pedir confirmación antes de ejecutarlos, por ejemplo en OpenCode con `"permission": { "bash": "ask" }`.
</Aside>
