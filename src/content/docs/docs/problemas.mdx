## Sesión vencida

**Síntoma:** el agente indica que se abrió una ventana para iniciar sesión.

Inicia sesión con Google en esa ventana y repite el pedido. Si la ventana no está visible, revisa detrás de otras ventanas o ejecuta:

```bash
npx -y unsada-mcp@latest login
```

Si el aula rechaza una sesión nueva, bórrala e inicia sesión otra vez:

```bash
npx -y unsada-mcp@latest logout
npx -y unsada-mcp@latest login
```

## Ventana de inicio de sesión ya abierta

**Síntoma:** *"A classroom sign-in window is already open."*

Solo puede haber una ventana a la vez. Termina el inicio de sesión en la ventana abierta, o ciérrala, y repite el pedido.

## Tiempo de inicio de sesión agotado

**Síntoma:** *"Five minutes passed without the user finishing the sign-in."*

La ventana espera cinco minutos. Ejecuta `npx -y unsada-mcp@latest login` otra vez.

## No se abre Edge ni Chrome

**Síntoma:** *"Could not open Edge or Chrome to sign in."*

- Instala [Microsoft Edge](https://www.microsoft.com/edge) o [Google Chrome](https://www.google.com/chrome/). Windows incluye Edge.
- Para elegir el navegador: `UNSADA_BROWSER=msedge` o `UNSADA_BROWSER=chrome`.
- En Linux, instala el paquete oficial de Chrome o Edge.

## Versión de Node.js antigua

**Síntoma:** aviso `EBADENGINE` de npm o errores al iniciar el servidor.

Se requiere Node.js 22 o superior. Verifica con `node -v` e instala la versión LTS de [nodejs.org](https://nodejs.org/) si es anterior. Después reinicia la terminal y el cliente.

<Aside>Con nvm o varias versiones de Node.js, el cliente puede usar una versión distinta a la de la terminal. Usa la ruta completa de `npx` en la configuración.</Aside>

## El cliente no encuentra npx (Windows)

**Síntoma:** el servidor no inicia, con `spawn npx ENOENT`, `Connection closed` o `-32000`.

Algunos clientes no pueden lanzar `npx` en Windows. Antepón `cmd /c`:

```bash
claude mcp add unsada -s user -- cmd /c npx -y unsada-mcp@latest
```

En JSON:

```json
{
  "mcpServers": {
    "unsada": { "command": "cmd", "args": ["/c", "npx", "-y", "unsada-mcp@latest"] }
  }
}
```

## El agente no muestra las herramientas

- Reinicia el cliente después de cambiar la configuración. Claude Desktop debe cerrarse también desde la bandeja del sistema.
- En Claude Code, `claude mcp list` muestra el estado del servidor.
- Verifica que el JSON sea válido. Una coma sobrante hace que el cliente ignore el archivo.

## Archivos descargados no encontrados

Los archivos se guardan en la carpeta desde donde el cliente inició el servidor. La respuesta de `unsada_download` incluye la ruta completa en `directory`. Con Claude Desktop, configura `UNSADA_DOWNLOAD_ROOTS` (ver [Descargas](../descargas/)).

## Archivo no legible

Los `.doc` y `.ppt` antiguos, `.zip`, `.rar` y videos no se pueden leer. Descárgalos con `unsada_download`.

## Datos incorrectos o vacíos

El servidor interpreta las mismas páginas que muestra el navegador. Un cambio de versión o de diseño del aula puede romper esa interpretación. Abre un [issue en GitHub](https://github.com/EmilioGiordano/unsada-mcp/issues) con el pedido y la respuesta, sin datos personales.
