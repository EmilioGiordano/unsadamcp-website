El aula usa Moodle 3.2, sin servicio para apps móviles, y se entra con Google. Por eso no hay usuario ni contraseña que cargar: el servidor usa tu propio navegador.

<Steps>

1. Ejecuta el comando de login en una terminal:

   ```bash
   npx -y unsada-mcp login
   ```

2. Se abre una ventana pequeña del navegador en el aula, directo en la pantalla de Google. En Windows prueba primero con **Edge** y después con Chrome; en macOS y Linux, al revés.

3. Entras con tu cuenta. Cuando el aula te reconoce, la ventana se cierra sola y la terminal dice:

   ```
   Listo: sesión iniciada. Ya podés usar unsada-mcp desde tu cliente MCP.
   ```

</Steps>

Tienes cinco minutos para completar el login. Si cierras la ventana antes, no pasa nada: vuelve a ejecutar el comando.

## Después del primer login

- **No hace falta repetirlo.** Mientras el servidor está corriendo, le avisa al aula cada 10 minutos que la sesión sigue en uso.
- **Si la sesión vence**, el servidor vuelve a abrir la ventana solo cuando tu agente necesita algo. Como Google ya te recuerda, suele bastar un clic. El agente te pedirá que termines de entrar y lo volverá a intentar.
- **Para cambiar de cuenta**, pídele al agente que vuelva a entrar (usa `unsada_login`) o ejecuta `npx -y unsada-mcp logout` y después `login`.

## Comprobar la sesión

```bash
npx -y unsada-mcp status
```

Te dice si hay una sesión guardada, por ejemplo `Conectado (sesión iniciada el …).`, o `Sin sesión: corré unsada-mcp login.` si tienes que entrar.

## Dónde queda guardada

| Sistema | Carpeta |
|---|---|
| Windows | `%APPDATA%\unsada-mcp` |
| Linux y macOS | `~/.config/unsada-mcp` |

Ahí están la sesión del aula y el perfil del navegador que usa la ventana de login (separado de tu perfil de siempre). Nada de eso sale de tu computadora. Puedes cambiar la carpeta con `UNSADA_MCP_HOME`.

<Aside type="caution">
  Quien tenga acceso a esa carpeta puede usar tu sesión del aula, como con cualquier navegador con la sesión abierta. Si usas una computadora compartida, ejecuta `npx -y unsada-mcp logout` al terminar.
</Aside>
