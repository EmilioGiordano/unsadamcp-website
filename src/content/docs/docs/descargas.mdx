`unsada_download` guarda archivos del aula en el disco. Es la única herramienta que escribe.

## Ubicación

Los archivos se guardan en una subcarpeta, elegida por el modelo, de la **carpeta donde se abrió el agente**. Con Claude Code abierto en `C:\Facultad` y la subcarpeta `Bases de Datos/Unidad 1`, el destino es `C:\Facultad\Bases de Datos\Unidad 1`. Las carpetas se crean si no existen.

Abre el agente en la carpeta de la facultad, no en la carpeta de usuario.

<Aside title="Claude Desktop y otras apps de escritorio">
  Estas apps inician el servidor en una carpeta que elige la app. Agrega la carpeta de destino a `UNSADA_DOWNLOAD_ROOTS` e indica la ruta completa, por ejemplo *"descárgalo en D:\Facultad\Bases de Datos"*.
</Aside>

## Reglas

- **Sin sobrescritura.** Un archivo con el mismo nombre y tamaño se omite. Si el tamaño difiere, el nuevo se guarda con el sufijo ` (2)`.
- **Sin carpetas ocultas ni de configuración.** Ninguna parte de la ruta puede empezar con punto (`.git`, `.claude`, `.vscode`) ni ser `node_modules`.
- **Nombres sensibles con prefijo.** Los archivos de instrucciones de agentes o que Windows procesa solo (`CLAUDE.md`, `AGENTS.md`, `desktop.ini`, `autorun.inf`) se guardan con `_` delante, por ejemplo `_CLAUDE.md`, para que no actúen como instrucciones.
- **Nombres válidos en Windows.** Los caracteres `<>:"/\|?*` se reemplazan por `_` y se evitan nombres reservados como `CON` o `NUL`.
- **Contención.** Cada ruta final se resuelve y se valida antes de escribir, incluidos los enlaces simbólicos.
- **Escritura atómica.** Cada archivo se descarga a un temporal y se renombra al terminar. No quedan archivos incompletos.

Límites: hasta 200 archivos por pedido y 500 MB por archivo.

## Permitir otras carpetas

`UNSADA_DOWNLOAD_ROOTS` define carpetas adicionales, separadas por `;` (Windows) o `:` (Linux y macOS). El modelo solo puede usar rutas absolutas dentro de ellas.

<Tabs syncKey="os">
  <TabItem label="Windows">
    Configuración del cliente, por ejemplo Claude Desktop:

    ```json
    {
      "mcpServers": {
        "unsada": {
          "command": "npx",
          "args": ["-y", "unsada-mcp@latest"],
          "env": { "UNSADA_DOWNLOAD_ROOTS": "D:\\Facultad;C:\\Users\\tu-usuario\\Documents\\Apuntes" }
        }
      }
    }
    ```

    Con Claude Code: `claude mcp add unsada -s user -e UNSADA_DOWNLOAD_ROOTS="D:\Facultad" -- npx -y unsada-mcp@latest`.
  </TabItem>
  <TabItem label="macOS y Linux">
    ```json
    {
      "mcpServers": {
        "unsada": {
          "command": "npx",
          "args": ["-y", "unsada-mcp@latest"],
          "env": { "UNSADA_DOWNLOAD_ROOTS": "/home/tu-usuario/Facultad:/home/tu-usuario/Apuntes" }
        }
      }
    }
    ```

    Con Claude Code: `claude mcp add unsada -s user -e UNSADA_DOWNLOAD_ROOTS="$HOME/Facultad" -- npx -y unsada-mcp@latest`.
  </TabItem>
</Tabs>

<Aside type="caution">
  Agrega solo carpetas de material. No uses la carpeta de usuario, la de inicio de Windows ni carpetas con proyectos de código: un archivo descargado podría ejecutarse o leerse como configuración.
</Aside>
