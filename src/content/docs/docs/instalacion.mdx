## Requisitos

- Node.js 22 o superior
- Microsoft Edge o Google Chrome

Para verificar Node.js, ejecuta `node -v`: debe mostrar `v22` o superior.

## 1. Instalar Node.js

<Tabs syncKey="os">
  <TabItem label="Windows">
    <Steps>

    1. Descarga el instalador **LTS** de [nodejs.org](https://nodejs.org/) y ejecútalo con las opciones por defecto.

    2. Abre una terminal nueva (PowerShell o Windows Terminal) y comprueba la versión:

       ```powershell
       node -v
       ```

    </Steps>

    <Aside>Las terminales abiertas antes de la instalación no encuentran `node`. Abre una nueva.</Aside>
  </TabItem>
  <TabItem label="macOS">
    Con el instalador de [nodejs.org](https://nodejs.org/) o con Homebrew:

    ```bash
    brew install node
    node -v
    ```
  </TabItem>
  <TabItem label="Linux">
    Con el gestor de paquetes de la distribución o con [nvm](https://github.com/nvm-sh/nvm):

    ```bash
    nvm install --lts
    node -v
    ```

    Para elegir el navegador, usa `UNSADA_BROWSER` (ver [Comandos y variables](../comandos/)).
  </TabItem>
</Tabs>

## 2. Iniciar sesión

`npx` descarga y ejecuta [`unsada-mcp`](https://www.npmjs.com/package/unsada-mcp). No requiere instalación previa.

```bash
npx -y unsada-mcp@latest login
```

Se abre una ventana de Google para entrar al aula. Ver [Primer inicio de sesión](../primer-login/).

## 3. Configurar el cliente

<Tabs syncKey="client">
  <TabItem label="Claude Code">
    `-s user` lo registra para todos los proyectos.

    ```bash
    claude mcp add unsada -s user -- npx -y unsada-mcp@latest
    ```

    Para verificarlo: `claude mcp list`.
  </TabItem>
  <TabItem label="Claude Desktop">
    En **Settings → Developer → Edit Config**, agrega el servidor a `claude_desktop_config.json`:

    ```json
    {
      "mcpServers": {
        "unsada": { "command": "npx", "args": ["-y", "unsada-mcp@latest"] }
      }
    }
    ```

    En Windows, el archivo está en `%APPDATA%\Claude\claude_desktop_config.json`. Cierra Claude Desktop por completo, también desde la bandeja del sistema, y vuelve a abrirlo.
  </TabItem>
  <TabItem label="Codex">
    En `~/.codex/config.toml` (en Windows, `%USERPROFILE%\.codex\config.toml`):

    ```toml
    [mcp_servers.unsada]
    command = "npx"
    args = ["-y", "unsada-mcp@latest"]
    ```
  </TabItem>
  <TabItem label="OpenCode">
    En `opencode.json`:

    ```json
    {
      "mcp": {
        "unsada": { "type": "local", "command": ["npx", "-y", "unsada-mcp@latest"] }
      }
    }
    ```
  </TabItem>
  <TabItem label="Cursor">
    En `~/.cursor/mcp.json` (global) o `.cursor/mcp.json` (por proyecto):

    ```json
    {
      "mcpServers": {
        "unsada": { "command": "npx", "args": ["-y", "unsada-mcp@latest"] }
      }
    }
    ```
  </TabItem>
</Tabs>

Reinicia el cliente. Para probarlo: *"¿Qué materias tengo este año?"*.

<Aside type="caution" title="npx en Windows">
  Algunos clientes no pueden lanzar `npx` en Windows (`spawn npx ENOENT` o `-32000`). Antepón `cmd /c`: `claude mcp add unsada -s user -- cmd /c npx -y unsada-mcp@latest`, o en JSON `"command": "cmd", "args": ["/c", "npx", "-y", "unsada-mcp@latest"]`. Más en [Solución de problemas](../problemas/).
</Aside>

## Actualizar

Reinicia el cliente: `@latest` descarga la última versión al iniciar. Una versión nueva puede tardar unos minutos en estar disponible.

## Desde el código

Para modificar el servidor o usarlo sin npm:

```bash
git clone https://github.com/EmilioGiordano/unsada-mcp
cd unsada-mcp
npm install
npm run build
claude mcp add unsada -s user -- node C:/ruta/a/unsada-mcp/build/index.js
```

Inicio de sesión: `node build/index.js login`.
