Cuando le pides *"descárgame el material de Bases de Datos"*, el agente usa `unsada_download`. Es lo único del servidor que escribe, y solo en tu disco.

## Dónde guarda

Dentro de la **carpeta donde abriste el agente**, en la subcarpeta que elija el modelo. Si abriste Claude Code en `C:\Facultad` y el modelo elige `Bases de Datos/Unidad 1`, los archivos quedan en `C:\Facultad\Bases de Datos\Unidad 1`. La carpeta se crea si no existe.

Por eso conviene abrir el agente en la carpeta donde guardas las cosas de la facultad, no en tu carpeta de usuario.

<Aside title="Claude Desktop y otras apps de escritorio">
  Las apps que no se abren en una carpeta (como Claude Desktop) lanzan el servidor desde una carpeta que elige la app, y puede no ser la que esperas. Con ellas, agrega tu carpeta de la facultad a `UNSADA_DOWNLOAD_ROOTS` (ver abajo) y pídele al agente que guarde ahí con la ruta completa, por ejemplo *"descárgalo en D:\Facultad\Bases de Datos"*.
</Aside>

## Reglas

- **Nunca sobrescribe un archivo.** Si ya existe uno con el mismo nombre y el mismo tamaño, lo omite. Si es distinto, guarda el nuevo con ` (2)` al final del nombre.
- **Nada en carpetas ocultas** ni de configuración: ninguna parte de la ruta puede empezar con punto (`.git`, `.claude`, `.vscode`…) ni ser `node_modules`.
- **Nombres sensibles con guion bajo.** Un archivo que se llame como las instrucciones de un agente o algo que Windows ejecuta solo (`CLAUDE.md`, `AGENTS.md`, `desktop.ini`, `autorun.inf`…) se guarda con `_` adelante, por ejemplo `_CLAUDE.md`. Así un archivo del aula no se convierte en instrucciones para tu agente.
- **Nombres válidos en Windows.** Cambia los caracteres no permitidos (`<>:"/\|?*`) por `_` y evita nombres reservados como `CON` o `NUL`.
- **Sin salirse de la carpeta.** Cada ruta final se resuelve y se comprueba antes de escribir, también si hay enlaces simbólicos en el camino.
- **Escritura segura.** Cada archivo se descarga a un temporal en la misma carpeta y solo al final toma su nombre, así no quedan archivos a medias.

Límites: hasta 200 archivos por pedido y 500 MB por archivo.

## Permitir otras carpetas

Si quieres que pueda guardar fuera de la carpeta donde abriste el agente, agrega las carpetas a la variable `UNSADA_DOWNLOAD_ROOTS`. Se separan con `;` en Windows y con `:` en Linux y macOS. El modelo puede usar una ruta absoluta solo si está dentro de una de ellas.

<Tabs syncKey="os">
  <TabItem label="Windows">
    En la configuración del cliente, por ejemplo Claude Desktop:

    ```json
    {
      "mcpServers": {
        "unsada": {
          "command": "npx",
          "args": ["-y", "unsada-mcp"],
          "env": { "UNSADA_DOWNLOAD_ROOTS": "D:\\Facultad;C:\\Users\\tu-usuario\\Documents\\Apuntes" }
        }
      }
    }
    ```

    Con Claude Code: `claude mcp add unsada -s user -e UNSADA_DOWNLOAD_ROOTS="D:\Facultad" -- npx -y unsada-mcp`.
  </TabItem>
  <TabItem label="macOS y Linux">
    ```json
    {
      "mcpServers": {
        "unsada": {
          "command": "npx",
          "args": ["-y", "unsada-mcp"],
          "env": { "UNSADA_DOWNLOAD_ROOTS": "/home/tu-usuario/Facultad:/home/tu-usuario/Apuntes" }
        }
      }
    }
    ```

    Con Claude Code: `claude mcp add unsada -s user -e UNSADA_DOWNLOAD_ROOTS="$HOME/Facultad" -- npx -y unsada-mcp`.
  </TabItem>
</Tabs>

<Aside type="caution">
  Agrega solo carpetas de material. Nunca tu carpeta de usuario entera, la de inicio de Windows ni una con proyectos de código: ahí un archivo descargado podría terminar ejecutándose o leído como configuración.
</Aside>
